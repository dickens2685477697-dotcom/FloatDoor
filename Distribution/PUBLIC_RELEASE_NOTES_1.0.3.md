## Float Door v1.0.3 — 滚动条位置修复

修复 v1.0.2 中滚动条覆盖素材内容的问题。

### 更新内容

- 滚动条移到内容右侧的独立空间，不再压在素材卡片和编辑文本上。
- 轨道保持透明，保留原生滑块和滚动操作。
- 一次性、长期素材、自定义区域和新建素材文本编辑框统一调整。

### 兼容与验证

- macOS 14+，Universal 安装包支持 Apple Silicon 和 Intel，构建号 4。
- 37 项测试通过，包括滚动条与内容区域不重叠的布局检查。
- 数据目录、Bundle ID 与数据格式保持兼容。
- 安装包采用临时签名，未经过 Apple 公证，沿用预览版状态；首次安装可能被 Gatekeeper 拦截。
- 尚未完成干净账户安装及真实 Intel 设备验证。

### 安装

下载 `FloatDoor-1.0.3.dmg`，退出旧版应用后，将 Float Door 拖入 Applications。随附 SHA-256 文件用于校验下载完整性。
