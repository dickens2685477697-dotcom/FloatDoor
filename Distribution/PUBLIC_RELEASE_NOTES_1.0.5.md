## Float Door v1.0.5 — 卡片复制操作

### 新增复制选项

- 卡片右键菜单新增“复制”，无需拖拽或使用快捷键即可将内容写入系统剪贴板。
- 卡片“更多操作”菜单同步新增“复制”选项。
- 多选项目后从右键菜单复制，会一次复制全部已选项目。
- 继续支持文本、链接、图片和文件的原有剪贴板格式。

### 兼容与验证

- macOS 14+，Universal 安装包支持 Apple Silicon 与 Intel，构建号 6。
- 39 项测试通过，包含菜单首击响应、操作路由、多选及剪贴板载荷验证。
- 保持现有数据目录、Bundle ID 和数据格式。
- 本安装包采用临时签名，尚未经过 Apple 公证，沿用预览版状态。首次安装可能被 Gatekeeper 拦截。
- 尚未完成干净账户安装及真实 Intel 设备验证。

### 安装

下载 `FloatDoor-1.0.5.dmg`，退出旧版 Float Door 后拖入 Applications。随附 SHA-256 文件可用于校验完整性。
