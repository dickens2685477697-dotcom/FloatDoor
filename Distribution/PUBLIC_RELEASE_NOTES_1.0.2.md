## Float Door v1.0.2 — 无轨道滚动条

本次为 v1.0.1 的小版本视觉修正。

### 更新内容

- 删除滚动条底部轨道，仅保留浮在内容上方的原生滑块。
- 一次性、长期素材、自定义区域及新建素材文本编辑框统一采用这一样式。
- 保留原生滚动和滑块拖动，视图更新后继续应用统一样式。

### 兼容与验证

- macOS 14+，Universal 安装包支持 Apple Silicon 和 Intel，构建号 3。
- 保留已有数据目录、Bundle ID 与数据格式。
- 原有 35 项测试与新增 2 项滚动区域集成测试通过。
- 与 v1.0.1 一样采用临时签名，尚未经过 Apple 公证，因此作为预览版发布；首次安装可能被 Gatekeeper 拦截。
- 尚未完成干净账户安装及真实 Intel 设备验证。

### 安装

下载 `FloatDoor-1.0.2.dmg`，退出旧版应用后，将 Float Door 拖入 Applications。随附 SHA-256 文件可用于校验下载完整性。
