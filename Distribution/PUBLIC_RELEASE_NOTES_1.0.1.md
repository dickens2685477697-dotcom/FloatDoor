## Float Door v1.0.1 — 更清爽、更易读

本次聚焦视觉层级与内容可读性。

### 视觉效果更新

- **顶部更简洁**：移除重复的数量胶囊，统计只保留在一次性 / 长期切换栏。
- **卡片更轻**：降低区域边框、卡片高光和阴影强度，减少层层套框的厚重感；选中与拖入状态仍然清晰。
- **小字更清楚**：区域说明、内容摘要、时间和空状态辅助文字调整到 11 pt，并提高亮度。
- **列表更安静**：以“5 分钟前”“剩余 23 小时”呈现时间，不再显示秒数；只有距离清理一小时以内显示橙色，已到期显示红色。

### 兼容与验证

- macOS 14+，Universal 安装包支持 Apple Silicon 和 Intel。
- 保持窗口尺寸、点击和拖放区域、Bundle ID 与本地数据格式。
- 35 项自动化测试通过，包含面板点击、拖放、选择、持久化和时间边界测试。
- 本版本采用临时签名，未通过 Apple 公证，作为预览版提供；首次安装可能被 Gatekeeper 拦截。
- 尚未完成干净账户安装、真实 Intel 设备及覆盖安装验证。

### 已有改动随版本收录

- 收录工作区已有的单实例启动保护和独立应用图标。
- 同步发布包许可与署名文件。
- 使用独立示例数据完成一次性列表、长期双栏与空状态的离屏布局检查；尚未完成真实桌面交互视觉验收。

### 安装

下载 `FloatDoor-1.0.1.dmg`，将 Float Door 拖入 Applications。安装前退出旧版本。可使用随附的 SHA-256 文件校验安装包。
