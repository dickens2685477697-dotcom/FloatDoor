## Float Door v1.1.0 — 鼠标减速唤起

### 唤起体验

- 鼠标进入顶部触发区域后，只有放慢或停稳才会自动展开，快速划过不再唤起面板，减少误触。
- 在触发区域内，鼠标速度不超过 120 点/秒并持续 0.15 秒后展开；鼠标停住后仍会继续检测，无需再次移动。
- 拖拽内容到刘海附近时使用相同的速度判断，保留稍大的拖拽触发区域。
- 离开触发区域、速度重新超过阈值、显示器布局改变或主动展开/收起时，会重置判断；拖拽提前松开鼠标也会取消待唤起状态。
- 主动点击触发区域或菜单栏入口仍可立即打开。收起动画期间重新进入触发区域，动画结束后会重新判断速度。

### 兼容与验证

- macOS 14+，Universal 安装包支持 Apple Silicon 与 Intel，构建号 7。
- 57 项测试通过，包含速度判断、快速划过、减速停稳、离开重入、拖拽释放和静止鼠标定时采样，以及原有面板与存储回归测试。
- 保持现有数据目录 `~/Library/Application Support/FloatDoor`、Bundle ID `com.floatdoor.app` 和数据格式，升级无需迁移数据。
- 本安装包采用临时签名，尚未经过 Apple 公证，沿用预览版状态。首次安装可能被 Gatekeeper 拦截。
- 尚未完成干净账户安装及真实 Intel 设备验证。

### 安装

下载 `FloatDoor-1.1.0.dmg`，退出旧版 Float Door 后拖入 Applications，允许替换旧版本。随附 SHA-256 文件可用于校验完整性。
