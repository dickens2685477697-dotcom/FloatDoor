## Float Door v1.0.4 — 弹窗体验与图标细节优化

### 弹窗体验

- 新建素材、区域重命名及素材重命名采用独立编辑子窗口。
- 编辑窗口打开和关闭时，主面板保持原有位置、尺寸和亮度，不再跳动或变暗。
- 去除系统弹窗遮罩造成的灰色直角边，保留主面板圆角外的透明区域。
- 关闭编辑窗口后保持面板展开；编辑期间阻止操作穿透到下方素材，避免误触。

### 图标细节

- 保留三个内容图标与毛玻璃托盘造型，移除穿过图标的多余横线。
- 蓝色圆按钮内的导入箭头从 15 pt 放大至 25 pt，按钮尺寸保持不变。

### 兼容与验证

- macOS 14+，Universal 安装包支持 Apple Silicon 与 Intel，构建号 5。
- 39 项测试通过，包含五个编辑入口、面板位置与亮度保持、圆角透明度检查。
- 保持现有数据目录、Bundle ID 和数据格式。
- 本安装包采用临时签名，尚未经过 Apple 公证，沿用预览版状态。首次安装可能被 Gatekeeper 拦截。
- 尚未完成干净账户安装及真实 Intel 设备验证。

### 安装

下载 `FloatDoor-1.0.4.dmg`，退出旧版 Float Door 后拖入 Applications。随附 SHA-256 文件可用于校验完整性。
