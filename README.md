# Float Door

Float Door是一款基于 macOS 顶部中央区域的本地内容暂存工具。

## 下载

请前往本仓库的 **Releases** 页面下载最新的 `FloatDoor-x.y.z.dmg`。

## 安装与更新

1. 打开 DMG。
2. 将“Float Door”拖入 Applications。
3. 更新时允许 Finder 替换旧版本。

应用数据保存在 `~/Library/Application Support/FloatDoor`。覆盖安装只替换应用本身，不会删除已有素材和数据库。建议在重要更新前自行备份该目录。

## 系统要求

- macOS 14 或更高版本
- Apple Silicon 或 Intel Mac
