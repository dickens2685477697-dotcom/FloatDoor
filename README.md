# Mac 任意门

Mac 任意门是一款基于 macOS 顶部中央区域的本地内容暂存工具。

## 下载

请前往本仓库的 **Releases** 页面下载最新的 `MacAnyDoor-x.y.z.dmg`。

## 安装与更新

1. 打开 DMG。
2. 将“Mac 任意门”拖入 Applications。
3. 更新时允许 Finder 替换旧版本。

应用数据保存在 `~/Library/Application Support/MacAnyDoor`。覆盖安装只替换应用本身，不会删除已有素材和数据库。建议在重要更新前自行备份该目录。

## 系统要求

- macOS 14 或更高版本
- Apple Silicon 或 Intel Mac

## 源码与扩展

Mac 任意门核心应用为闭源软件。本下载仓库不包含核心源码。未来的 Extension SDK、接口定义和示例扩展将作为独立的公开内容发布，用户可在公开接口范围内进行定制；这不授予访问、修改或再分发核心源码的权利。

## 隐私

素材和数据库默认只保存在本机。应用不会自动上传本地内容。
